# Track photograph attribution

These photographs are licensed separately from the project software licence.
Sixteen photographs were downloaded from Wikimedia Commons on 25 October 2026
as thumbnails up to 960 pixels wide.
Files are resized versions of the originals (Mikkeli was already smaller).
The directory crops images visually to a uniform frame; profiles show the full image.
The UI displays creator, year, source, licence, and the resize/crop notice.
These are historical photographs, not current track-condition images.

## Ylivieska: official-source photograph

`track-y.jpg` is the Ylivieska photograph in the
[Suomen Hippos track directory](https://www.hippos.fi/raviurheilu/raviurheilu-lajina/suomen-raviradat/).
[Published image](https://www.hippos.fi/uploads/sites/1/2021/05/b08b71a4-ylivieska_suvi_hakkarainen-1024x683.jpg),
1024 × 683 pixels, downloaded unchanged on 25 October 2026 for this local directory.
The published filename credits Suvi Hakkarainen. The capture date and an open
licence are not supplied by the page. The catalog explicitly records rights as
`not-specified`, and the UI links to the publisher instead of asserting a CC licence.
This photo is not covered by the Commons licences above. Obtain permission before
redistributing it or publishing it as a reusable project asset.
